# Songroost

A relaxing bird-collecting, engine-building game for 1–6 players, played in the browser on phones and tablets.

- Plays close to the original board game's rules, with five rounds that move from Dawn to Nightfall.
- Our own art, birds and sounds, starting with the Amazon Rainforest.
- A living board: a flowing river, fish, a prowling black jaguar, a squirrel monkey in the canopy, and soft rainforest ambience.

Play it at **https://songroost.github.io** (work in progress).
